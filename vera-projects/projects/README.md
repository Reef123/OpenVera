# projects/

Each subdirectory here is one project, generated by `/build new` or `/start-here`. Every project is self-contained.

A typical project folder holds:

- `CLAUDE.md` — project metadata + machine-readable frontmatter
- `spec.md` — what this project does, stack, cut list
- `idea.md` — present if the project came from `/start-here`
- `build-state.md` — state machine managed by `build-state.py`
- `retro.md`, `v1-checklist.md` — post-ship artifacts
- `.build/` — ephemeral V0 artifacts (contract, validation, review, screenshots)
- `plans/` — durable V1+ SDLC artifacts (PRD, tech spec, arch review, phase plans, QA, ship log)
- `research/` — any `/research` output scoped to this project
- your scaffolded code (`src/`, `tests/`, `package.json`, etc.)

The full canonical layout lives in `.claude/skills/build/build-architecture.md`.

Contents of each subdirectory are gitignored by the harness — your work stays local unless you explicitly track it in your own repo.

# Panel — retired

**`/panel` is retired as of v1.21 ("the one gate").** Its goal — pressure-test
a bet against perspectives you can't generate yourself before spending build
hours — is real, but an audit of panel's real run history (2026-07-02) found the
domain-reviewer scan half was evidence-free role-play (fired once, ever) and
the interview half (the old Step 6b "Deeper understanding") was the actual
value. Rather than run two separate gates, the interview is now the single
gate and it absorbed the one honest piece of panel: an evidence-or-cut
blind-spot scan folded in as a gate move, not a separate ceremony.

**Where it went:**
- The interview → `/build new` Stage 0, offered by default, soft (skip with
  one word). Method: `vera-system/memory/interview-method.md`.
- The bet/audience/problem lint → still `vera-system/scripts/artifact-lint.py
  --profile idea`, now called directly by the Stage 0 gate.
- The scope-diff → still runs, inside the Stage 0 gate.
- The domain-reviewer scan → replaced by evidence-or-cut lenses inside the
  interview (a lens needing outside facts gets scout/web access or is cut;
  no more read-only role-play reviewers).
- The severity/confidence scoring (`panel-score.py`) and the "log is training
  data" claim → cut. Both were theater: unmeasured self-rated inputs given a
  false patina of precision, and a learning loop with zero data (its would-be
  consumer, `/improve` calibration, ships in 1.22 alongside outcome-tracking).

**If you're here because a skill or doc told you to run `/panel`:** that
reference is stale — run `/build new` instead; its Stage 0 will offer the
interview gate automatically.

This file deletes in the next release. Nothing in the harness calls it.
